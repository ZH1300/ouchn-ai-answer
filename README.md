# 📝 国开 LMS AI 答案解析助手

> 一个运行在 Tampermonkey 上的油猴脚本。自动获取国家开放大学 LMS 考试题目，调用 DeepSeek API 生成参考答案，并以卡片形式展示。**仅展示答案，不自动选择、不自动提交。**

---

## ✨ 功能特性

- **自动拉题**：从当前考试页面自动识别 `examId`，请求 LMS 接口获取题目，无需手动复制题干
- **AI 解析**：逐题调用 DeepSeek，输出结构化的参考答案
- **题型适配**：支持单选、多选、判断、填空、简答、论述；判断题答案自动归一化为「正确 / 错误」
- **答案可读**：选择题自动把字母映射为「B. 选项文本」，方便与页面核对
- **卡片展示**：每题一张卡片，含题号、题型、分值、已作答状态、题干、选项与答案
- **一键复制**：支持单题复制与全部答案复制（纯文本格式）
- **浮动面板**：可拖动、可拖拽缩放、双击标题栏最大化/还原、可最小化；位置与尺寸自动记忆
- **加密存储**：API Key 使用主密码 + AES-GCM 256 加密后本地保存，不明文落盘
- **多路径容错**：题目接口按优先级尝试多条候选路径，兼容不同考试页面结构

## 📦 安装

### 前置条件

1. 浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）
2. 拥有一个可用的 [DeepSeek API Key](https://platform.deepseek.com/)（需自行注册并充值）

### 安装脚本

**方式一：从文件安装**

1. 下载本仓库的 `ouchn-ai-answer.user.js`
2. 打开 Tampermonkey 管理面板 → 点击「实用工具」→「导入」→ 选择该文件
3. 确认安装

**方式二：新建脚本粘贴**

1. 打开 Tampermonkey 管理面板 → 点击「+」新建脚本
2. 删除默认模板，粘贴本仓库 `.user.js` 文件的全部内容
3. `Ctrl + S` 保存

## 🚀 使用

### 第一步：登录 LMS

在浏览器中正常登录国家开放大学学习平台，进入考试页面。URL 形如：

```text
https://lms.ouchn.cn/exam/{考试ID}/...
```

### 第二步：配置 API Key

页面右下角会自动出现脚本面板。点击 **「API Key」** 按钮：

1. 输入你的 DeepSeek API Key（形如 `sk-xxxxxxxx`）
2. 设置一个主密码（**至少 6 位，请务必记住**）
3. 确认后，Key 会以加密形式保存在本地

> 主密码仅用于本地解密，不会上传到任何服务器。**忘记主密码将无法恢复已保存的 Key**，只能清除后重新设置。

### 第三步：开始解析

点击 **「开始获取答案」**：

1. 首次或刷新页面后，会弹出主密码输入框用于解锁 Key
2. 脚本依次拉取题目并调用 AI
3. 每完成一题，面板中立即出现一张答案卡片
4. 全部完成后点击 **「📋 复制全部答案」** 导出文本清单

### 面板操作

| 操作 | 方式 |
|---|---|
| 移动面板 | 按住标题栏拖动 |
| 调整大小 | 拖动右下角 ◢ 手柄 |
| 最大化 / 还原 | 双击标题栏 |
| 最小化 | 点击标题栏 `—` |
| 关闭面板 | 点击标题栏 `✕` |
| 重新打开 | Tampermonkey 菜单 → 「📝 显示 AI 答案解析面板」 |

## 🛡️ 安全与隐私

### 数据流向

| 数据 | 去向 | 说明 |
|---|---|---|
| 题干、选项、题型 | `api.deepseek.com` | 用于生成答案，不包含任何身份信息 |
| 浏览器 Cookie | `lms.ouchn.cn` | 由浏览器自动附带，脚本不读取、不保存、不外传 |
| DeepSeek API Key | `api.deepseek.com` | 通过 `Authorization` 头发送；本地以加密形式保存 |
| 主密码 | 仅本地内存 | 不落盘、不上传，用完即弃 |

### 加密存储机制

- 算法：**AES-GCM 256-bit**
- 密钥派生：**PBKDF2 + SHA-256，150,000 次迭代**
- 盐与 IV：每次加密随机生成，与密文一同存储
- 存储内容：`{ v, salt, iv, data }`，无明文 Key
- 明文 Key 仅在当前页面内存中短暂存在，刷新即失效

### 不会做的事

- ❌ 不读取、不打印、不转发浏览器 Cookie
- ❌ 不向 `lms.ouchn.cn` 和 `api.deepseek.com` 之外的任何域名发请求
- ❌ 不远程加载代码，不使用 `eval`
- ❌ 不自动选择答案、不自动提交试卷
- ❌ 不采集任何个人信息

### 权限说明

| `@grant` | 用途 |
|---|---|
| `GM_xmlhttpRequest` | 请求 LMS 题目接口与 DeepSeek API（受 `@connect` 白名单限制） |
| `GM_setValue` / `GM_getValue` | 保存加密 Key 与面板位置尺寸 |
| `GM_deleteValue` | 清除本地加密 Key |
| `GM_registerMenuCommand` | 注册油猴菜单入口 |

`@match` 仅限 `https://lms.ouchn.cn/exam/*` 与 `https://lms.ouchn.cn/api/exams/*`，不匹配其他页面。

## ⚙️ 配置项

脚本顶部 `CONFIG` 对象可调整：

```javascript
const CONFIG = {
    DEEPSEEK_API_KEY: '',   // 运行时填充，无需手动修改
    DEEPSEEK_URL: 'https://api.deepseek.com/v1/chat/completions',
    REQUEST_DELAY: 1500,    // 每题之间延时（毫秒），可调大以降低风控风险
    MAX_RETRY: 2            // 单题 AI 调用失败重试次数
};
```

| 配置 | 默认 | 说明 |
|---|---|---|
| `REQUEST_DELAY` | `1500` | 若平台返回 429 或频繁验证，建议调至 `3000` 以上 |
| `MAX_RETRY` | `2` | AI 接口超时或返回异常时的重试次数 |

## ❓ 常见问题

**Q1：点击「开始获取答案」后提示「未获取到题目」怎么办？**

按 `F12` 打开控制台，观察 `[AI答题]` 开头的日志，确认脚本尝试了哪些接口。若全部失败，请在 Network 面板中手动找到考试页面加载时真正返回题目（含 `subjects` 字段）的 XHR 请求 URL，将其补充到脚本 `fetchQuestions()` 的 `candidates` 数组首位。其余解析逻辑通用，无需改动。

**Q2：主密码忘记了怎么办？**

无法找回。请通过 Tampermonkey 菜单 → 「🗑️ 清除本地加密 API Key」，然后重新设置。

**Q3：为什么每次刷新页面都要重新输入主密码？**

解密后的 Key 只保存在当前页面内存中，刷新即失效。这是出于安全考虑的设计，避免明文 Key 长期驻留。

**Q4：脚本会自动帮我填答案或交卷吗？**

不会。本脚本**只展示答案**，不点击选项、不填入输入框、不提交试卷。所有操作需你自行完成。

**Q5：答案准确率如何？**

答案由 DeepSeek 生成，仅供参考。涉及专业术语、计算题或主观题时可能存在偏差，请务必结合课程资料自行判断。

**Q6：是否支持其他 LMS 平台？**

当前版本针对国家开放大学 LMS 的接口结构（`subjects` 数组、`description` 题干、`single_selection` / `true_or_false` 题型）适配。其他平台需修改 `fetchQuestions()` 与 `normalizeQuestion()`。

## 🧩 技术说明

- **运行环境**：Tampermonkey（支持 `GM_xmlhttpRequest`、`GM_setValue` 等 API）
- **题目解析**：优先读取 `json.subjects`，递归兜底搜索；过滤 `type=text` 且无选项且分值为 0 的章节标题
- **题干清洗**：`DOMParser` 解码 HTML，保留段落换行，规范化空白
- **选项字母**：按 `options[].sort` 排序后自动生成 `A/B/C/D`
- **AI 输出约束**：通过 `response_format: { type: 'json_object' }` 强制 JSON 输出，解析失败自动重试
- **面板持久化**：`GM_setValue('panel_state', { left, top, width, height })`
