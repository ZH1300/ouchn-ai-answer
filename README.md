## ✨ 功能特性

### 核心能力

- **自动拉题**:从当前考试页面自动识别 `examId`,多路径容错请求 LMS 接口获取题目,无需手动复制题干
- **全题型适配**:单选、多选、判断、填空(含多空)、简答、程序题、论述题全覆盖
- **答案可读**:选择题自动把字母映射为 `B. 选项文本`;判断题归一化为「正确 / 错误」;填空题按空位标注 `空1:…;空2:…`
- **智能分流**:程序题自动识别「写出运行结果 / 编写程序 / 分析函数功能」三类,分别定制提示词
- **卡片展示**:每题一张卡片,含题号、题型、分值、已作答状态、题干、选项与答案
- **一键复制**:支持单题复制与全部答案复制(纯文本格式)

### 面板与交互

- **浮动面板**:可拖动、可拖拽缩放、双击标题栏最大化/还原、可最小化
- **状态持久化**:位置、尺寸、最小化前的尺寸均自动记忆
- **任务可控**:关闭面板即停止正在运行的任务,不浪费 API 配额

### 安全与隐私

- **加密存储**:API Key 使用主密码 + PBKDF2(15 万次迭代)+ AES-GCM-256 加密后本地保存
- **免密解锁**:解锁时可选择「记住 7 天」或本会话内自动复用,避免每次刷新重复输入主密码
- **会话缓存二次加密**:sessionStorage 中的 Key 使用 IndexedDB 中不可导出的设备密钥再次加密
- **隐私确认**:首次运行前弹窗告知题干会外发 DeepSeek,需明确确认

### 性能

- **低 token**:单条 user 消息、极简指令、短键 `a`、按题型限 `max_tokens`,单题 input tokens 减少约 43%
- **高准确**:`temperature:0` 消除随机性,程序题三路分流,判断题只答「对/错」
- **内存精简**:不保留原始题目对象,卡片使用事件委托与 class 化样式

## 📦 安装

### 前置条件

1. 浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)(Chrome / Edge / Firefox / Safari 均可)
2. 拥有一个可用的 [DeepSeek API Key](https://platform.deepseek.com/)(需自行注册并充值)

2. 删除默认模板,粘贴本仓库 `.user.js` 文件的全部内容
3. `Ctrl + S` 保存

## 🚀 使用

### 第一步:登录 LMS 并进入考试页

在浏览器中正常登录国家开放大学学习平台,进入考试页面。URL 形如:

```text
https://lms.ouchn.cn/exam/{考试ID}/...
```

脚本会在页面加载后约 1.2 秒在右下角自动创建面板。

### 第二步:配置 API Key

点击 **「API Key」** 按钮,按对话框提示操作:

1. 输入你的 DeepSeek API Key(形如 `sk-xxxxxxxx`)
2. 设置一个主密码(**至少 6 位,请务必记住**)
3. 可选勾选「记住 7 天」(本机自动解锁,公共电脑请勿勾选)
4. 确认后,Key 会以加密形式保存在本地

> 主密码仅用于本地解密,不会上传到任何服务器。**忘记主密码将无法恢复已保存的 Key**,只能清除后重新设置。

### 第三步:开始解析

点击 **「开始获取答案」**:

1. 首次使用会弹出**隐私确认**(题干会发送至 DeepSeek),确认后不再重复
2. 若已保存过 Key,会弹出主密码解锁框(勾选了「记住 7 天」且在有效期内可跳过)
3. 脚本依次拉取题目并逐题调用 AI
4. 每完成一题,面板中立即出现一张答案卡片
5. 全部完成后点击 **「📋 复制全部答案」** 导出文本清单

### 第四步:核对与提交

脚本**不会**自动填入或提交。请根据卡片中的答案自行在考试页面完成作答与提交。

## 📚 题型支持

| LMS `type` | 显示名称 | AI 输出格式 | 展示格式 |
|---|---|---|---|
| `single_selection` | 单选题 | `{"a":"B"}` | `B. 选项文本` |
| `multiple_selection` | 多选题 | `{"a":"ACD"}` | `A. …;C. …;D. …` |
| `true_or_false` | 判断题 | `{"a":"对"}` 或 `{"a":"错"}` | `正确` / `错误` |
| `fill_in_blank` / `fill_blank` | 填空题 | `{"a":["答案1","答案2"]}` | `空1:…;空2:…` |
| `short_answer`(结果题) | 简答题 | `{"a":"15 20"}` | 原文输出 |
| `short_answer`(编程题) | 程序题 | `{"a":"#include<...>..."}` | 完整 C 代码 |
| `short_answer`(功能题) | 简答题 | `{"a":"功能简述"}` | 一句话说明 |
| `essay` | 论述题 | `{"a":"要点"}` | 论点摘要 |
| `text`(分值为 0) | — | 自动过滤,不作为题目 | — |

### 填空题空位识别

LMS 填空题题干中空位为 `<span class="__blank__">…<span class="circle-number">N</span>…</span>`,脚本会提取其中的序号替换为 `【空N】`,AI 据此按序返回答案数组,展示时按 `空1:…;空2:…` 格式标注。

### 程序题三路分流

对于 `short_answer` 类型,脚本根据题干内容自动判断:

| 判断依据 | 分流 | 提示词特点 |
|---|---|---|
| 含「编写 / 编程 / 设计程序」 | 编写题 | 要求返回完整可编译的 C 源码(含 `#include` 与 `main`) |
| 含「功能 / 作用」 | 功能题 | 要求 ≤30 字中文说明 |
| 含 `#include` / `void main` / `int main`,或含「输出 / 打印 / 运行结果」 | 结果题 | 要求返回输出原文,空格原样保留,换行用 `\n` 表示,不加解释 |

## 🛡️ 安全与隐私

### 数据流向

| 数据 | 存放位置 / 去向 | 说明 |
|---|---|---|
| 题干、选项、题型 | `api.deepseek.com` | 用于生成答案,**不包含** 考试 ID、题目 ID、个人身份信息 |
| 浏览器 Cookie | `lms.ouchn.cn` | 由浏览器自动附带,脚本**不读取、不保存、不外传** |
| DeepSeek API Key(持久) | 浏览器 Tampermonkey 存储 | PBKDF2 + AES-GCM-256,主密码不存储 |
| DeepSeek API Key(记住 7 天) | 浏览器 Tampermonkey 存储 | 使用 IndexedDB 中不可导出的设备密钥加密 |
| DeepSeek API Key(会话缓存) | sessionStorage | 设备密钥加密,12 小时过期 |
| 主密码 | 仅本地内存 | 不落盘、不上传,用完即弃 |
| 题目与答案 | 内存 | 页面关闭即释放 |

### 加密存储机制

- **算法**:AES-GCM 256-bit
- **密钥派生**:PBKDF2 + SHA-256,150,000 次迭代
- **盐与 IV**:每次加密随机生成,与密文一同存储
- **存储内容**:`{ v, salt, iv, data }`,无明文 Key
- **设备密钥**:IndexedDB 中 `extractable: false` 的 `CryptoKey`,JS 无法导出其原始字节
- **明文 Key**:仅在当前页面内存中短暂存在;「记住 7 天」时使用设备密钥加密,不会以明文落在任何存储介质上

### 不会做的事

- ❌ 不读取、不打印、不转发浏览器 Cookie
- ❌ 不向 `lms.ouchn.cn` 和 `api.deepseek.com` 之外的任何域名发请求
- ❌ 不远程加载代码,不使用 `eval`
- ❌ 不自动选择答案、不自动提交试卷
- ❌ 不采集任何个人信息
- ❌ 不发送考试 ID、题目 ID、分值等非必要字段

### 权限说明

| `@grant` | 用途 |
|---|---|
| `GM_xmlhttpRequest` | 请求 LMS 题目接口与 DeepSeek API(受 `@connect` 白名单限制) |
| `GM_setValue` / `GM_getValue` | 保存加密 Key、面板位置尺寸、隐私确认状态 |
| `GM_deleteValue` | 清除本地加密 Key 与记住状态 |
| `GM_registerMenuCommand` | 注册油猴菜单入口 |

`@match` 仅限 `https://lms.ouchn.cn/exam/*` 与 `https://lms.ouchn.cn/api/exams/*`,不匹配其他页面。

### 安全建议

- **公共 / 考场电脑**:解锁时**不要勾选**「记住 7 天」;离开前执行菜单「🔒 立即锁定」或「🗑️ 清除本地加密 API Key」
- **个人电脑**:可勾选「记住 7 天」,体验最佳
- 清除浏览器站点数据或换浏览器后,「记住 7 天」状态会失效,需重新解锁

## ⚙️ 配置项

脚本顶部 `CONFIG` 对象可调整:

```javascript
const CONFIG = {
    DEEPSEEK_API_KEY: '',   // 运行时填充,无需手动修改
    DEEPSEEK_URL: 'https://api.deepseek.com/v1/chat/completions',
    REQUEST_DELAY: 1500,    // 每题之间延时(毫秒),可调大以降低风控风险
    MAX_RETRY: 2            // 单题 AI 调用失败重试次数
};
```

| 配置 | 默认 | 说明 |
|---|---|---|
| `REQUEST_DELAY` | `1500` | 若平台返回 429 或频繁验证,建议调至 `3000` 以上 |
| `MAX_RETRY` | `2` | 网络错误、解析失败、429、5xx 时的重试次数;4xx 不重试 |

### Token 消耗参考

以 37 题试卷为例(含单选、填空、程序题等混合题型):

- input tokens:约 2,400
- output tokens:约 1,500
- 合计:约 **4,000 tokens**

对比通用 prompt 方案(约 7,000+ tokens),节省约 43%。

## ❓ 常见问题

**Q1:点击「开始获取答案」后提示「未获取到题目」怎么办?**

按 `F12` 打开控制台,观察 `[AI答题]` 开头的日志,确认脚本尝试了哪些接口。若全部失败,请在 Network 面板中手动找到考试页面加载时真正返回题目(含 `subjects` 字段)的 XHR 请求 URL,将其补充到脚本 `fetchQuestions()` 的 `candidates` 数组首位。其余解析逻辑通用,无需改动。

**Q2:主密码忘记了怎么办?**

无法找回。请通过 Tampermonkey 菜单 → 「🗑️ 清除本地加密 API Key」,然后重新设置。

**Q3:为什么有时还需要重新输入主密码?**

自 v4.1 起已支持免密:

- 同一标签页刷新:会话缓存有效(12 小时),无需重输
- 勾选了「记住 7 天」:7 天内打开页面自动解锁
- 清除浏览器数据 / 换浏览器 / 超过有效期:需重新输入

这是出于安全考虑的设计,避免明文 Key 长期驻留。若需立即锁定,用菜单「🔒 立即锁定」。

**Q4:脚本会自动帮我填答案或交卷吗?**

不会。本脚本**只展示答案**,不点击选项、不填入输入框、不提交试卷。所有操作需你自行完成。

**Q5:答案准确率如何?**

答案由 `deepseek-chat` 生成,`temperature:0`,仅供参考。选择题与判断题准确率较高;简答与程序题建议提交前自行核对。

**Q6:是否支持其他 LMS 平台?**

当前版本针对国家开放大学 LMS 的接口结构(`subjects` 数组、`description` 题干、`fill_in_blank` / `single_selection` / `true_or_false` 等题型)适配。其他平台需修改 `fetchQuestions()`、`normalizeQuestion()` 与 `buildPrompt()`。

**Q7:答案中出现「选项未匹配」是什么意思?**

AI 返回了字母但该字母不在当前选项内(通常因 AI 幻觉或选项解析失败)。该题答案需人工核对。

**Q8:面板卡顿 / 内存占用高?**

v4.4 起已精简内存与 DOM 对象。若仍卡顿,通常是题目较多(>100 题)导致卡片 DOM 累积,可关闭面板后重新开始,或最小化面板。

**Q9:可以换用其他 AI 接口吗?**

修改 `CONFIG.DEEPSEEK_URL` 并确保接口兼容 OpenAI Chat Completions 格式与 `response_format: { type: 'json_object' }` 即可,例如 Ollama、vLLM 部署的兼容接口。

**Q10:为什么第一次运行要确认隐私?**

脚本会把题干发送到第三方(DeepSeek)生成答案,这属于数据外发,必须让用户知情并确认。该提示只出现一次,记录在 `privacy_ack_v1` 中,可通过清除 Tampermonkey 存储重置。

## 🧩 技术说明

### 运行环境

- Tampermonkey(支持 `GM_xmlhttpRequest`、`GM_setValue` 等 API)
- 现代浏览器(需支持 `crypto.subtle`、IndexedDB、`DOMParser`)

### 题目解析

- 优先读取 `json.subjects`,递归兜底搜索
- 过滤 `type=text` 且无选项且分值为 0 的章节标题(`isSectionHeader`)
- `answer_number` 对填空题表示空数而非作答状态,不误标「已作答」

### 题干清洗

- `DOMParser` 解码 HTML,保留段落换行,规范化空白
- 填空题 `__blank__` 空位替换为 `【空N】`,便于 AI 按序作答

### 选项字母

- 按 `options[].sort` 排序后自动生成 `A/B/C/D`

### AI 输出约束

- `response_format: { type: 'json_object' }` 强制 JSON 输出
- 短键 `a` 降低模型「加 reason 字段」倾向
- JSON 解析使用括号配对 + 字符串状态机兜底,避免贪婪正则截取
- 解析失败自动重试(最多 `MAX_RETRY` 次)

### 请求重试策略

| 错误类型 | 是否重试 | 退避 |
|---|---|---|
| 网络错误 / 超时 | ✅ | 1s / 2s |
| JSON 解析失败 | ✅ | 0.8s / 1.6s |
| HTTP 429 | ✅ | 2s / 4s / 8s(上限 15s) |
| HTTP 5xx | ✅ | 1s / 2s |
| HTTP 4xx(除 429) | ❌ 立即抛错 | — |

### 面板持久化

`GM_setValue('panel_state', { left, top, width, height })`;最小化时保存的是还原后的高度,不会把 header 高度误存。

## 📅 版本历史

### v4.5(当前)

- **低 token 高准确请求**:删除 system 消息、短键 `a`、按题型限 `max_tokens`、`temperature:0`
- **程序题三路自动分流**:结果题 / 编程题 / 功能题各自最优指令
- **判断题简化为「对/错」**:减少 AI 映射歧义;展示层仍还原为「正确/错误」
- 单题 input tokens 减少约 43%

### v4.4

- **内存精简**:不再保留 `raw` / `id` 等原始字段;`lastResults` 只存格式化结果
- **事件委托**:卡片复制按钮不再创建闭包
- **class 化样式**:一次注入 `<style>`,卡片使用 class
- **复用单例**:`DOMParser` / `TextEncoder` / `TextDecoder` 模块级复用

### v4.3

- **安全修复**:sessionStorage 中的 API Key 改为设备密钥二次加密
- **隐私提示**:首次运行前弹出原生确认
- **任务生命周期**:新增 `runToken` 与 `isRunning` 互斥,关闭面板即停
- **最小化 / 最大化状态机**:修复尺寸持久化错乱
- **请求健壮性**:4xx 不重试,429 指数退避;`onerror` 包装为可读 Error
- **判断题**:按实际选项文本映射,未匹配时保留字母 + 文本

## ⚠️ 已知限制

1. **仅适配国开 LMS**:接口结构依赖 `subjects` 数组与 `description` 字段,其他平台需改代码
2. **不自动答题**:只展示答案,所有操作需人工完成
3. **答案不保证 100% 正确**:AI 生成内容仅供参考,需自行核对
4. **依赖 DeepSeek 服务可用性**:接口超时或限流时可能部分题目失败,可调大 `REQUEST_DELAY` 重试
5. **题目数过多时面板 DOM 累积**:>100 题时可能出现卡顿,建议分批运行
6. **风控风险**:短时间大量请求可能触发 LMS 或 DeepSeek 风控,脚本已内置 1.5 秒间隔与指数退避,但无法完全避免
